📖 Comandos de Búsqueda

Puedes usar estos comandos en la barra de búsqueda:

ID:1000 Buscar por Event ID específico
MSG:error conexión Buscar texto en mensajes
LVL:error Filtrar por nivel (error, warning, info, critical, detailed)
texto normal Sin comando, busca en todos los mensajes

Ejemplos:

  • ID:4624 - Eventos con ID 4624
  • MSG:failed login - Mensajes con "failed login"
  • LVL:critical - Solo eventos críticos
